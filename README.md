# [Cidade Jardim: Conheça Alegee]

> Conheça a cidade mais bonita do Sul do Espirito Santo (Conhecida pela natureza, edifícios históricos e o famoso festival de música.)

## 📝 Descrição
Nesse projeto, o objetivo é apresentar a cidade de Alegre. Localizada no sul do Espírito Santo, é carinhosamente conhecida como "Cidade Jardim". O título se deve à grande quantidade de praças bem cuidadas, ruas arborizadas e floridas que encantam os visitantes na região do Caparaó. 

## 🚀 Tecnologias Utilizadas
Este projeto está sendo desenvolvido com as seguintes ferramentas:

*   **Controle de Versão:** Git e GitHub.
*   **Front-end:** HTML5, CSS3, JavaScript.
*   **Ambiente:** VS Code.
*   **Hospedagem:** GitHub Pages.
